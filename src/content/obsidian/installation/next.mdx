## Requirements

- Next.js with the App Router
- Tailwind CSS v4
- A project initialized with shadcn/ui (`npx shadcn@latest init`)

## Installation

<Tabs items={["pnpm", "npm", "yarn", "bun"]}>
  <Tab value="pnpm">
    ```bash
    pnpm dlx shadcn@latest add https://www.mspaint.cc/r/obsidian
    ```
  </Tab>
  <Tab value="npm">
    ```bash
    npx shadcn@latest add https://www.mspaint.cc/r/obsidian
    ```
  </Tab>
  <Tab value="yarn">
    ```bash
    yarn dlx shadcn@latest add https://www.mspaint.cc/r/obsidian
    ```
  </Tab>
  <Tab value="bun">
    ```bash
    bunx --bun shadcn@latest add https://www.mspaint.cc/r/obsidian
    ```
  </Tab>
</Tabs>

This adds the components to `components/obsidian`, installs `dompurify`, `lucide-react`, `@radix-ui/react-tabs`, `@react-three/fiber` and `three`, and registers the `no-scrollbar` utility in your global CSS file.

To update to the latest version, run the same command again and overwrite the existing files.

### Demo page

If you also want the demo page shown above, add the `obsidian-demo` item. It creates `app/obsidian-demo/page.tsx` together with an example `ObsidianExtracted.json`:

```bash
npx shadcn@latest add https://www.mspaint.cc/r/obsidian-demo
```

<Callout type="info">
  The `icon` prop is rendered with `next/image`. When using a remote URL, add its host to `images.remotePatterns` in your `next.config.ts`.
</Callout>

## Usage

The UI can be built either from JSX components or from an extracted JSON file.

### Components

```tsx
import {
  Obsidian,
  ObsidianTab,
  ObsidianSubTab,
  ObsidianLeft,
  ObsidianRight,
  ObsidianGroupbox,
  ObsidianTabWarning,
  ObsidianToggle,
  ObsidianSlider,
  ObsidianInput,
  ObsidianDropdown,
  ObsidianButton,
  ObsidianLabel,
  ObsidianDivider,
  ObsidianKeyBox,
  DropdownDivider
} from "@/components/obsidian/obsidian";
```

```tsx
<Obsidian
  title="mspaint"
  icon="/mspaint.png"
  footer="version: example"
  //width={720}
  //height={600}
>
  <ObsidianTab name="General" order={0} icon="Settings" description="General settings">
    <ObsidianTabWarning visible title="Warning" text="This is a tab warning." isNormal />

    <ObsidianLeft>
      <ObsidianGroupbox name="Basics" order={0} icon="Box" description="Groupbox <b>descriptions</b> support rich text.">
        <ObsidianToggle text="Enable feature" defaultChecked />
        <ObsidianToggle text="Risky feature" risky variant="Checkbox" />
        <ObsidianSlider text="Opacity" min={0} max={100} value={80} suffix="%" />
        <ObsidianInput text="Display name" placeholder="Type your name" />
        <ObsidianDivider text="Mode" />
        <ObsidianDropdown text="Mode" options={["Simple", DropdownDivider("More"), "Advanced"]} />
        <ObsidianButton text="Apply" subButtonText="Reset" subButtonRisky />
      </ObsidianGroupbox>
    </ObsidianLeft>

    <ObsidianRight>
      <ObsidianGroupbox name="Info" order={0}>
        <ObsidianLabel text="This is a label." />
        <ObsidianLabel text="This is a long label that wraps onto multiple lines." doesWrap />
      </ObsidianGroupbox>
    </ObsidianRight>
  </ObsidianTab>

  <ObsidianTab name="Visuals" order={1} icon="Eye">
    <ObsidianSubTab name="Players" order={0}>
      <ObsidianLeft>
        <ObsidianGroupbox name="ESP">
          <ObsidianToggle text="Enabled" />
        </ObsidianGroupbox>
      </ObsidianLeft>
    </ObsidianSubTab>

    <ObsidianSubTab name="World" order={1}>
      <ObsidianLeft>
        <ObsidianGroupbox name="Lighting">
          <ObsidianToggle text="Fullbright" />
        </ObsidianGroupbox>
      </ObsidianLeft>
    </ObsidianSubTab>
  </ObsidianTab>

  <ObsidianTab name="Key" order={2} icon="Key" isKeyTab>
    <ObsidianLabel text="Enter your key below." doesWrap />
    <ObsidianKeyBox placeholder="Key" />
  </ObsidianTab>
</Obsidian>
```

Icons use [Lucide](https://lucide.dev/icons) component names in PascalCase, such as `Settings` or `SettingsIcon`. Roblox asset ids and image URLs also work.

### Extracted JSON

If you want to automatically dump your Obsidian UI to a JSON file, you can use the following script which will save a file named `ObsidianExtracted.json` in your executor's `workspace` folder:
```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/mspaint-cc/assets/refs/heads/main/uidata/extractor.lua"))()
```

Import the file and pass it to the `uiData` prop. When `uiData` is set, children are ignored:
```tsx
import { Obsidian } from "@/components/obsidian/obsidian";
import UIData from "./ObsidianExtracted.json";

<Obsidian title="mspaint" icon="/mspaint.png" footer="version: example" uiData={UIData} />
```

The [test view page](/obsidian-test) lets you preview an extracted JSON file before adding it to your project.
