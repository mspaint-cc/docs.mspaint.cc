## Usage

You can create a Viewport by calling the `AddViewport` method on a Groupbox.

### Arguments

```lua
local Viewport = Groupbox:AddViewport("MyViewport", {
    Object = Instance.new("Part"),
    Camera = Instance.new("Camera"),
    Interactive = true,
    AutoFocus = true,
    Height = 200,
})
```

| Arg Idx | Argument Description | Type | Default |
| --- | --- | --- | --- |
| 1 | Index/ID of the viewport element | string | nil |
| 2 | Viewport configuration table | table | nil |

## Methods

You can use the following methods to interact with the viewport element:

#### SetObject
Changes the displayed 3D object.

```lua
Viewport:SetObject(object)
```

| Arg Idx | Argument Description | Type | Default |
| --- | --- | --- | --- |
| 1 | Object instance to display | Instance | nil |

#### SetCamera
Updates the camera instance.

```lua
Viewport:SetCamera(camera)
```

| Arg Idx | Argument Description | Type | Default |
| --- | --- | --- | --- |
| 1 | Camera instance | Instance (Camera) | nil |

#### SetCameraCFrame
Sets the CFrame of the viewport camera.

```lua
Viewport:SetCameraCFrame(CFrame.new(0, 5, 10))
```

| Arg Idx | Argument Description | Type | Default |
| --- | --- | --- | --- |
| 1 | New camera CFrame | CFrame | nil |

#### GetCameraCFrame
Returns the current CFrame of the viewport camera.

```lua
local CameraCFrame = Viewport:GetCameraCFrame()
```

#### Rotate
Orbits the camera around the object pivot. Pitch is limited so the camera can't flip over the top.

```lua
Viewport:Rotate(45) -- 45 degrees to the side
Viewport:Rotate(0, 15) -- 15 degrees up
```

| Arg Idx | Argument Description | Type | Default |
| --- | --- | --- | --- |
| 1 | Yaw in degrees | number | 0 |
| 2 | Pitch in degrees | number? | 0 |

#### Zoom
Moves the camera forwards (positive) or backwards (negative) along its look direction.

```lua
Viewport:Zoom(2)
Viewport:Zoom(-2)
```

| Arg Idx | Argument Description | Type | Default |
| --- | --- | --- | --- |
| 1 | Amount of studs to move | number | nil |

#### LookAt
Points the camera at a position without moving it. Defaults to the object pivot.

```lua
Viewport:LookAt()
Viewport:LookAt(Vector3.new(0, 2, 0))
```

| Arg Idx | Argument Description | Type | Default |
| --- | --- | --- | --- |
| 1 | Position to look at | Vector3? | Object pivot |

#### SetDistance
Moves the camera to a specific distance from the object pivot, keeping its current direction.

```lua
Viewport:SetDistance(10)
```

| Arg Idx | Argument Description | Type | Default |
| --- | --- | --- | --- |
| 1 | Distance in studs (must be higher than 0) | number | nil |

#### GetDistance
Returns the distance between the camera and the object pivot. Returns `0` if there is no object.

```lua
local Distance = Viewport:GetDistance()
```

#### SetFieldOfView
Sets the field of view of the viewport camera. The value is clamped between 1 and 120.

```lua
Viewport:SetFieldOfView(50)
```

| Arg Idx | Argument Description | Type | Default |
| --- | --- | --- | --- |
| 1 | Field of view in degrees | number | nil |

#### SetInteractive
Toggles user interaction.

```lua
Viewport:SetInteractive(interactive)
```

| Arg Idx | Argument Description | Type | Default |
| --- | --- | --- | --- |
| 1 | Whether the viewport is interactive | boolean | nil |

#### SetHeight
Adjusts the viewport frame height.

```lua
Viewport:SetHeight(height)
```

| Arg Idx | Argument Description | Type | Default |
| --- | --- | --- | --- |
| 1 | Frame height in pixels | number | nil |

#### Focus
Focuses the camera on the object.

```lua
Viewport:Focus()
```

| Arg Idx | Argument Description | Type | Default |
| --- | --- | --- | --- |
| 1 | *No arguments* | – | – |

#### SetVisible
Shows or hides the viewport element.

```lua
Viewport:SetVisible(visible)
```

| Arg Idx | Argument Description | Type | Default |
| --- | --- | --- | --- |
| 1 | Visibility toggle | boolean | nil |

#### Destroy
Destroys the viewport and removes it from the UI.

```lua
Viewport:Destroy()
```

## Example

```lua
local Options = Library.Options

local Viewport = Groupbox:AddViewport("DemoViewport", {
    Object = Instance.new("Part"),
    Camera = Instance.new("Camera"),
    Interactive = true,
    AutoFocus = true,
    Height = 240,
})

Viewport:SetInteractive(true)
Viewport:SetHeight(260)
Viewport:Focus()

Viewport:SetFieldOfView(50)
Viewport:SetDistance(8)
Viewport:Rotate(45, 15)
Viewport:LookAt()
```
